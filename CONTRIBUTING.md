# Contribuindo

O Monitor está em planejamento. Antes de implementar uma mudança grande, abra uma issue descrevendo o problema, o resultado esperado e a fase relacionada.

1. Consulte o briefing e o roteiro em `docs/ROADMAP.md`.
2. Crie uma branch para a alteração.
3. Documente comportamento, validação e limitações no pull request.
4. Inclua testes relevantes ao implementar funcionalidades.

Não inclua credenciais, dados reais de clientes, caixas de e-mail, bancos locais ou documentos pessoais. Use dados sintéticos. Integrações de WhatsApp e Instagram devem utilizar APIs oficiais.

Contribuições são disponibilizadas sob a licença MIT do projeto. Não publique código ou materiais de terceiros sem autorização compatível.
