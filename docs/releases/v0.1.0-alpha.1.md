# Monitor v0.1.0-alpha.1 — Base desktop

Primeira versão de desenvolvimento com interface e fluxo de demandas. A Fase 1 permanece em validação; esta pré-release não é indicada para depender de monitoramento ou lembretes de produção.

## Disponível

- Oito telas navegáveis baseadas no protótipo, com filtros por frente.
- Criar, editar e excluir demandas; persistência SQLite e histórico.
- Kanban, próxima ação, prioridade, prazo e data de retorno obrigatória em Acompanhar.
- Aplicativo Windows em Tauri com backend Python, autenticação local por sessão, bandeja, instância única e configuração de inicialização.
- Detecção do Ollama, modelo configurável e download explícito com progresso.
- Demonstração isolada; dados fictícios não se misturam ao banco real.

## Instalação e dados

Use o instalador `.exe` ou `.msi` para Windows x64. A versão interna numérica do MSI é `0.1.0.1`, correspondente a esta alpha. Os binários não têm assinatura Authenticode. Ollama e modelos são instalados separadamente.

O banco real fica em `%LOCALAPPDATA%\Monitor\monitor.db`. Fechar a janela mantém o aplicativo na bandeja; use Sair para encerrar. A inicialização com Windows pode ser ajustada nas configurações. Não há atualizador automático.

## Limitações

E-mails, sites, redes sociais, arquivos e chat são telas de demonstração ou preparação para fases futuras. Nenhuma conta está conectada, nenhum monitor de disponibilidade está ativo e não há conversa real com a LLM nesta versão. O download do modelo prepara o ambiente; não ativa análises ainda.

Alertas da bandeja, pausa de verificações e notificações de prazos dependem dos workers das próximas fases. Consulte `docs/VALIDATION.md` para testes e pendências.

## Validação

Build Windows aprovado para `2f0446d`, com cinco testes backend, dois testes de componentes e teste do sidecar. O fluxo de demandas foi testado com frontend, API e SQLite reais, simulando apenas a camada IPC. A janela nativa foi localizada, mas a inspeção manual pela ferramenta de controle do computador expirou aguardando autorização. Instalação e interação manual com bandeja/autostart permanecem para validação.
