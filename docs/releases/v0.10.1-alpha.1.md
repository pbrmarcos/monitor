# Monitor v0.10.1-alpha.1 — Importação de skills Markdown

- Botão **Importar skill .md**, com prévia para revisar nome, palavras-chave e instruções antes de salvar.
- Documentos completos de até 100 mil caracteres e 128 KB guardados para consulta, separados das instruções ativas de até 4.000 caracteres. Referências longas não são enviadas automaticamente ao modelo.
- Edição das skills personalizadas e migração das skills existentes.
- Skill **Remover padrões de escrita de IA** incluída numa adaptação curta para o Qwen3.5 4B, aplicada somente a revisões e reescritas.
- Mantidos o modelo selecionado, o contexto de 16.384 tokens e o limite de duas skills por pergunta. Nenhum modelo maior é baixado e não há treinamento dos pesos.

Skills são instruções textuais; não executam scripts, acessam arquivos ou instalam plugins de outros agentes. A saída ainda precisa de revisão: um modelo de 4B pode deixar passar regras de estilo ou alterar relações entre fatos.

Atualize em **Configurações → Verificar atualizações**, conclua a instalação e reabra o Monitor. Os instaladores Windows x64 `.exe` e `.msi` também estão disponíveis nesta release.
