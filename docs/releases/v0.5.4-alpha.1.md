# Monitor v0.5.4-alpha.1 — Versão e atualizações em destaque

- Painel **Versão e atualizações** no início das Configurações, com a versão instalada e o botão **Verificar atualizações**.
- A versão vem do próprio aplicativo desktop; o backend é usado como alternativa quando a leitura nativa não está disponível.
- O botão permanece visível após encontrar uma versão nova. A instalação continua sendo uma ação separada, pelo botão **Atualizar agora**.
- Mostra quando a versão já é a mais recente e quando a consulta falha. A prévia no navegador identifica que não representa um aplicativo instalado.

Testes da interface conferem a leitura da versão nativa, consulta somente após o clique e instalação separada da verificação. TypeScript/Vite e a navegação visual passaram.

O [build Windows](https://github.com/pbrmarcos/monitor/actions/runs/43310916978) passou e publicou os instaladores e o manifesto do atualizador com as assinaturas dos pacotes.

A instalação pelo atualizador ainda exige validação manual no Windows. As assinaturas dos pacotes não são Authenticode.
