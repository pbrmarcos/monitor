# Monitor v0.0.1 — Especificação inicial

Primeira pré-release pública do projeto Monitor, sob licença MIT.

## Incluído

- Briefing técnico com arquitetura proposta e sete fases de entrega.
- PDF de referência das telas.
- README, roteiro, orientações de contribuição e segurança.
- Estrutura inicial reservada para backend, frontend, desktop e relay.
- Regras de exclusão de credenciais, bancos e arquivos locais.

## Estado desta versão

Esta é uma release de documentação e planejamento. Não contém aplicativo funcional, instalador Windows ou integrações ativas. Nenhum teste funcional ou benchmark de IA foi executado, pois a implementação ainda não começou.

## Próxima entrega

Fase 1: base desktop com telas navegáveis, banco, demandas e kanban, seguida da validação do instalador Windows.
