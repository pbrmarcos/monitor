# Monitor v0.5.3-alpha.1 — Conversa geral e assistente de trabalho

- Na **Visão geral**, o assistente continua ajudando com demandas, e-mails, prazos, lembretes e sites, citando os registros consultados.
- Na tela **Assistente**, converse sobre qualquer assunto: ideias, estudos, explicações ou escrita. O chat tem instruções próprias e não recebe automaticamente os dados das suas frentes.
- Históricos separados durante a sessão. Trocar de tela mantém cada conversa; limpar uma não apaga a outra. Fechar o aplicativo encerra esses históricos.
- Sugestões de perguntas e textos de introdução adequados a cada conversa.
- O modelo continua sendo executado no Ollama local, sem navegação na internet nem execução de ações.

Validação local: testes da API verificam que a conversa geral não coleta o contexto comercial; testes da interface verificam o modo enviado, a separação dos históricos e a limpeza independente. TypeScript/Vite e a navegação visual em três larguras passaram.

O [build Windows](https://github.com/pbrmarcos/monitor/actions/runs/43307550998) passou e publicou os instaladores e o manifesto do atualizador com as assinaturas dos pacotes. O modelo usa as mensagens recentes de cada conversa.

Atualize em **Configurações → Aplicativo → Verificar atualizações** ou baixe o instalador. A instalação pelo botão continua pendente de validação manual no Windows; os pacotes têm assinaturas do atualizador, sem Authenticode.
